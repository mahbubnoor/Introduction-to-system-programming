Lab 1 · Introduction to System Programming

Present lecture 1 Slides (PDF)
  1. Write hello.c
    nano hello.c, type the program, save with Ctrl+O, exit with Ctrl+X.
  2. Run the four stages
    gcc -E, -S, -c, then link. Fill a table with wc -l and ls -l for all five files.
  3. Ask file what each file is
    file hello*. Which files are ELF? Which one is executable?
  4. Find the holes
    nm hello.o and objdump -d hello.o. Copy the line with 00 00 00 00.
  5. Count system calls
    strace -c ./hello. Then build with -static and count again.
  6. Know your machine
    Run endian.c and sizes.c. Then lscpu | grep -i cache and record the cache sizes.

Submit: your lab notebook with every command, its output, and one sentence per task. Bonus: why does the static file need fewer system calls?
