Lab 4 · Macro Processors

Present lecture 4 Slides (PDF)
  1. Build the starter
    gcc -Wall -o macro macro_starter.c then ./macro maccnt.asm. The output still says COMP &CH.
  2. TODO 1: DEFTAB
    Replace each parameter name by ?n when storing a line. Print DEFTAB and compare with slide 11.
  3. TODO 2 + 3: ARGTAB
    Split the call's operand at commas; replace ?n by ARGTAB[n−1], counting down.
  4. TODO 4: the label
    Put the call's label on the first generated line. diff with maccnt_expected.asm must print nothing.
  5. Into the assembler
    ./macro maccnt.asm > m.asm then your Lab 3 ./sicasm m.asm. The object program must match slide 7's run.
  6. TODO 5: $ labels
    Make twice.asm work: CNTCH called twice. Without TODO 5 your assembler reports duplicate symbol LOOP.

Submit: macro.c, the expanded twice.asm, and its object program from your Lab 3 assembler.
