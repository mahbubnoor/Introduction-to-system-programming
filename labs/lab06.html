Lab 6 · Object File Formats

Present lecture 6 Slides (PDF)
  1. TODO 1: the magic
    memcmp(buf, ELFMAG, SELFMAG). Test: ./elfread elfread.c must say "not an ELF file".
  2. TODO 2: sections
    Point an Elf64_Shdr array at e_shoff; names from .shstrtab. Compare with readelf -S main.o.
  3. TODO 3: symbols
    Use sh_link to find the names; ELF64_ST_TYPE and ELF64_ST_BIND. Compare with readelf -s.
  4. TODO 4: relocations
    Split r_info with ELF64_R_SYM and ELF64_R_TYPE. Check counta − 4 at offset 9.
  5. TODO 5: program headers
    Same pattern as TODO 2 with Elf64_Phdr. Try it on count and on tiny.
  6. Check everything
    ./elfread main.o | diff - expected_main.o.txt (and sections.o, tiny): no output means done.

Submit: elfread.c and its output for count. Extra: run it on a damaged file (bad) and on /bin/ls.
